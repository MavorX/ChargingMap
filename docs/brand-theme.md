# 公司主题色 · ChargingMap

## 来源与角色

参考公司提供的 `docs/presentation/VCTC Template_Rise Up.potx`：读取 `ppt/theme/theme1.xml` 的主题色，并参考版式中的荧光强调色；未采用模板附带的 Office 默认 `theme2`。

| 模板色                 | 色值                            | 界面用途                                 |
| ---------------------- | ------------------------------- | ---------------------------------------- |
| 品牌绿                 | `#008C82`                       | 主色基准、可用站点标记、充电状态         |
| 深色 / Deep Space Blue | `#002733`                       | 顶部导航、正文、深色界面基底             |
| 浅绿                   | `#99D1CD`                       | 选中描边、深色顶栏品牌字标               |
| 荧光强调 / Vivid Neon  | `#C2FE06`                       | 当前导航、账户选中与少量点缀，不铺满卡片 |
| 模板冷灰               | `#99A9AD`、`#CCD3D6`、`#4C6870` | 边框、说明、辅助信息与界面层级           |

`src/theme/palette.js` 是统一色板。Tailwind、地图站点与定位范围图形共用它，避免地图仍残留旧蓝色或另一套绿色。原有学院标志保留，不修改其图像色彩；PPT 原件不随本次代码提交。

## 使用原则

- 主按钮使用 `primary-600 / #007A72` 搭配白字；其与白色的对比度约 **5.22:1**。原始品牌绿与白字仅约 4.14:1，不用于小号按钮文字的底色。
- 荧光绿只能搭配深色文字或出现在深色底上；与 `#002733` 的对比度约 **13.06:1**。禁止荧光底白字，也不用于白底正文。
- 主操作、筛选、金额、充电进度及账户入口统一使用绿色系；快慢充通过文字与图标区分，不依赖蓝紫绿三套装饰色。
- 余位紧张保留琥珀色，已满与异常保留红色，维护保留灰色；同时保留文字状态和图例，不将品牌色用于所有业务状态。
- 地图信息窗采用与页面一致的浅/深色卡片、轻边框与实色按钮，移除状态色渐变头图及硬编码浅色统计块。信息窗已打开时也随主题改变，无须重建地图。
- 筛选主按钮、导航图标和详情分区取消多色渐变、扫光及发光。荧光点缀不覆盖电价、桩位和主要操作。
- 不随模板分发企业字体文件；继续使用系统中英文字体，不引入字体下载或新依赖。

## 保持不变

保留左侧列表及其收展路径、中英文、移动端布局和「选桩 → 接枪确认 → 检测启动 → 停止 → 拔枪 → 结算」流程。品牌适配不新增模式或改变演示数据。
